## 1. 获取 X (Twitter) Cookie 凭证

NewsCatcher 通过模拟 X 账户登录会话来自动访问和抓取推文，您需要提供对应 X 账号的两个核心 Cookie 参数：`auth_token` 与 `ct0`。

### 获取步骤：
1. 使用 Chrome / Edge 浏览器打开 [https://x.com](https://x.com) 并登录您的 Twitter 账号。
2. 按 `F12` 或右键选择“检查”，打开**开发者工具 (Developer Tools)**。
3. 切换到 **Application (应用)** 选项卡（Safari 浏览器为“存储”，Firefox 为“存储”）。
4. 在左侧展开 **Cookies** -> 点击 `https://x.com`。
5. 在右侧列表中找到以下两个键的值并复制：
   - `auth_token`: (一串 40 位的十六进制字符串)
   - `ct0`: (一串 32 位或以上的 CSRF 标记字符)
6. 打开 NewsCatcher 前端界面的 **“系统设置”** -> 在 **“X (Twitter) Cookie 凭证设置”** 中填入并点击 **“测试 Cookie 有效性”**。

> **提示**：如果测试返回登录成功并显示您的用户名，则说明 Cookie 配置成功。

## 2. 配置 AI 模型 (OpenAI 兼容 API)

NewsCatcher 能够对接任何兼容 OpenAI API 格式的大语言模型。

### 配置步骤：
1. 进入 **“系统设置”** -> **“OpenAI 兼容 API 对接”**。
2. 填写以下信息：
   - **API Base URL**：例如 `https://api.openai.com/v1`、`https://api.deepseek.com` 或本地 Ollama 的 `http://localhost:11434/v1`
   - **API Key**：您的 LLM 服务提供商提供的 API 密钥
   - **Model 名称**：例如 `gpt-4o`、`gpt-3.5-turbo`、`deepseek-chat` 或 `qwen2.5`
3. 点击 **“测试 AI 接口”** 确认连线正常。
4. 点击底部的 **“保存系统设置”**。

## 3. 添加与管理 X 抓取源

进入左侧导航栏的 **“抓取源管理”**，您可以自由添加监控规则：

- **关键词搜索 (Search)**：如 `OpenAI min_faves:50` (包含 OpenAI 且点赞数大于 50 的推文)
- **指定推主账号 (User)**：如 `from:SamA` (抓取 Sam Altman 发布的推文)
- **Hashtag 话题 (Hashtag)**：如 `#AI` 或 `#Finance`

可以随时通过开关启用/禁用某个抓取源，或点击删除按钮移除源。

## 4. 设置新闻分类与过滤规则

进入 **“系统设置”** -> **“新闻分类全功能管理与保留设置”**：

- **添加分类**：在输入框中输入新的分类名称（如 `加密货币`、`芯片`），点击“添加分类”。
- **删除分类**：点击分类标签右侧的 `×` 按钮，即可删除旧的或默认的分类。
- **勾选保留规则**：勾选框选中的分类表示**目标保留分类**。当 AI 在提炼推文后，只有被归类为已被勾选分类的新闻，才会保存到 SQLite 数据库中，未勾选的将被自动过滤丢弃。

## 5. 配置定时自动化抓取

在 **“系统设置”** -> **“自动定时抓取周期设置”**：

1. 开启 **“启用定时自动抓取”** 切换开关。
2. 设定时间间隔，如“每 `1` `小时` 自动抓取一次”或“每 `30` `分钟` 自动抓取一次”。
3. 保存设置后后台将按计划自动在后台静默运行。
4. 亦可在任何时候点击右上角的 **“立即抓取新闻”** 按钮进行手动触发。
5. 在 **“抓取日志”** 页面可以查看每一次运行的抓取条数、入库新闻数与执行状态。

---

## 6. 新闻浏览与 Markdown 阅读器

在 **“新闻简报”** 页面：

- **检索与过滤**：使用顶部搜索框可按标题、正文、作者模糊搜索；点击分类 Badge 卡片可按分类筛选。
- **查看 Markdown 详情**：点击任意新闻卡片，即可弹出基于 Material Design 3 样式的 Markdown 深入阅读器，包含由 AI 总结生成的背景、核心要点列表与原推链接。
